## 1. 数据结构与复杂度

- 字典（dict）：成员 -> score，O(1) 查找。
- 跳表（skiplist）：按 score 有序，区间查询 O(logN + M)。
- 插入、删除整体为 O(logN)。

## 2. 典型场景

- 排行榜、实时排名。
- 延迟任务（用 score 表示时间戳）。
