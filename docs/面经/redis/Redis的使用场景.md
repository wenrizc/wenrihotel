# Redis的使用场景

## 1. 结论

Redis 适合做高性能缓存与低延迟数据结构服务，常见用于缓存、会话管理、计数器、排行榜、限流与消息场景。

## 2. 典型场景

- 缓存热点数据，降低数据库压力。
- 会话与登录态存储。
- 计数器与限流（`INCR`、滑动窗口）。
- 排行榜（ZSet）。
- 延迟队列与轻量消息（List/Stream）。
- 分布式锁（`SET NX EX`）。

## 3. 注意事项

- 关注缓存一致性与失效策略。
- 控制内存占用与大 Key/热 Key 风险。
- 需要持久化时启用 RDB/AOF。
