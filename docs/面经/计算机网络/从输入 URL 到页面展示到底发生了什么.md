## 1. 主要流程

1. URL 解析与缓存：检查 HSTS、浏览器缓存、Service Worker。
2. DNS 解析：浏览器/系统/本地缓存 → 递归与权威 DNS 查询。
3. 建立连接：TCP 三次握手；HTTPS 还需 TLS 握手与证书验证。
4. 发送请求与服务端处理：路由、业务逻辑、数据库/缓存。
5. 接收响应：状态码、响应头、压缩（Gzip/Brotli）。
6. 浏览器渲染：解析 HTML 构建 DOM，解析 CSS 构建 CSSOM，生成渲染树，布局与绘制。
7. 资源加载：JS/CSS/图片等并发加载，可能触发重排/重绘。

## 2. 关键点与注意事项

- 缓存命中会跳过 DNS 或网络请求，流程会被明显缩短。
- HTTP/2 多路复用与连接复用可以减少握手与排队延迟。
- JS 会阻塞 DOM 解析，CSS 会阻塞渲染，关键资源要优先加载。
- CDN 就近回源与 TLS 会话复用可以显著降低 TTFB。
