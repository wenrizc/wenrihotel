## 1. 实现流程

1. 解析配置（XML/注解）并注册 `BeanDefinition`。
2. 实例化 Bean。
3. 依赖注入（构造器或属性）。
4. 生命周期回调与后置处理。
5. 将 Bean 放入容器供使用。

## 2. 关键点/注意事项

- `BeanFactory` 是核心接口，`ApplicationContext` 在其上提供扩展。
- 依赖注入方式决定了循环依赖的处理能力。
- AOP 与事务通常通过后置处理器创建代理。

## 3. 常见追问/易错点

- 追问：为什么构造器注入更推荐？
  - 答：核心结论是：IoC（控制反转）是由容器负责对象创建与依赖注入，Spring 通过 `BeanDefinition` 注册、反射实例化与生命周期回调实现这一机制。展开时可按“实现流程、关键点/注意事项”组织，先概述再逐点展开，保证结构完整。其中实现流程侧重解析配置（XML/注解）并注册 `BeanDefinition`，关键点/注意事项侧重`BeanFactory` 是核心接口，`ApplicationContext` 在其上提供扩展。回答时要体现步骤、关键点与适用场景，必要时补充示例或对比。
- 易错点：误以为 IoC 只等同于依赖注入，忽视生命周期管理。
  - 答：常见易错点是忽略步骤顺序或前置条件、遗漏关键点或注意事项。比如实现流程中提到：解析配置（XML/注解）并注册 `BeanDefinition`。关键点/注意事项中还提到：`BeanFactory` 是核心接口，`ApplicationContext` 在其上提供扩展。这些细节很容易被忽视。回答时应明确边界、关键步骤与适用场景，并用实例或对比验证。
