## 1. 注入方式概览

- 构造器注入：依赖不可变、易测试，适合必需依赖。
- Setter 注入：适合可选依赖或避免循环依赖。
- 字段注入（`@Autowired`）：方便但不利于测试与不可变性。
- 方法参数注入：在 `@Bean` 或配置方法中使用。

## 2. 选择建议

- 关键依赖使用构造器注入。
- 可选依赖使用 `@Autowired(required=false)` 或 `@Nullable`。
- 生产代码避免过度字段注入。

## 3. 常见追问/易错点

- 追问：`@Autowired` 与 `@Resource` 的差异是什么？
  - 答：核心结论是：Spring 主要支持构造器注入、Setter 注入、字段注入与方法参数注入，推荐优先使用构造器注入以保证依赖完整性。展开时可按“注入方式概览、选择建议”组织，先概述再逐点展开，保证结构完整。其中注入方式概览侧重构造器注入：依赖不可变、易测试，适合必需依赖，选择建议侧重关键依赖使用构造器注入。回答时要体现步骤、关键点与适用场景，必要时补充示例或对比。
- 易错点：字段注入导致循环依赖不易发现。
  - 答：常见易错点是只给结论不讲依据、边界条件与前提不清。比如注入方式概览中提到：构造器注入：依赖不可变、易测试，适合必需依赖。选择建议中还提到：关键依赖使用构造器注入。这些细节很容易被忽视。回答时应明确边界、关键步骤与适用场景，并用实例或对比验证。
