# Spring的三级缓存机制是什么

## 1. 结论

三级缓存用于解决单例 Bean 的循环依赖，分别是成品对象、早期对象与对象工厂，配合 AOP 生成代理。

## 2. 三级缓存内容

- `singletonObjects`：完整初始化的单例。
- `earlySingletonObjects`：提前暴露的半成品对象。
- `singletonFactories`：对象工厂，用于生成早期代理。

## 3. 工作流程

1. 创建 A 时暴露 `ObjectFactory`。
2. 创建 B 时引用 A 的早期对象。
3. A 初始化完成后替换为成品对象。

## 4. 注意事项

- 仅解决单例 Bean 的 setter 循环依赖。
- 构造器循环依赖、原型 Bean 无法解决。
