# JVM垃圾对象的判定标准

## 1. 结论

JVM 主要通过可达性分析判断对象是否可回收，无法从 GC Roots 到达的对象视为垃圾。

## 2. 判定方法

- 可达性分析算法（Reachability Analysis）。
- 引用类型：强引用、软引用、弱引用、虚引用。

## 3. 补充机制

- `finalize()` 仅一次且不可靠，不应依赖。
- 软/弱引用配合 `ReferenceQueue` 做缓存与资源释放。
