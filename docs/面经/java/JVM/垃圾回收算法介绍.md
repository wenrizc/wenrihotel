## 1. 主要算法

- 标记-清除：实现简单，但易碎片化。
- 复制算法：速度快但需要额外空间，适合新生代。
- 标记-整理：减少碎片，适合老年代。
- 分代收集：结合对象存活率特征，综合使用。

## 2. 关键点/注意事项

- 碎片化会影响大对象分配。
- 分代策略依赖“朝生夕死”假设。
