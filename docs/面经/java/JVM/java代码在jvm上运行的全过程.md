## 1. 主要流程

1. `javac` 编译生成 `.class` 字节码。
2. 类加载：加载、链接（验证/准备/解析）、初始化。
3. 解释器执行字节码。
4. JIT 将热点代码编译为本地机器码。
5. GC 在运行期间回收内存。

## 2. 关键点/注意事项

- 类加载时的验证确保字节码安全。
- JIT 会基于热点统计进行优化。
- 运行期的类加载可能影响启动与性能。
