## 1. 常见 Roots 类型

- 各线程虚拟机栈中的局部变量。
- 方法区中类的静态变量。
- JNI 引用与本地方法栈对象。
- JVM 内部对象（如系统类加载器、异常类）。

## 2. 关键点/注意事项

- Roots 可达并不代表一定“有用”，只是不能回收。
- 过多长生命周期引用容易造成内存泄漏。
