# 设置对象头过程介绍

## 1. 结论

对象创建时 JVM 会初始化对象头（Mark Word、Klass 指针；数组还含长度），以支持哈希、锁状态与类型信息。

## 2. 设置过程

1. 分配内存并填充对象字段零值。
2. 写入 Mark Word（锁状态、hashcode、GC 标记）。
3. 写入 Klass 指针指向类元数据。
4. 若为数组对象，写入数组长度。

## 3. 关键点/注意事项

- 偏向锁、轻量级锁等会复用 Mark Word。
- 对象头大小与 JVM 参数（如开启压缩指针）有关。
