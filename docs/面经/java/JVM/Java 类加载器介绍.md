# Java 类加载器介绍

## 1. 结论

Java 类加载器分为 Bootstrap、Platform/Extension、Application 以及自定义加载器，遵循双亲委派模型以保障核心类安全与一致性。

## 2. 类加载器层级

- Bootstrap：加载 `java.lang` 等核心类库。
- Platform/Extension：加载扩展库（JDK 自带平台类）。
- Application：加载应用类路径下的类。
- Custom：按需加载特定来源（如插件、热部署）。

## 3. 工作机制

- `loadClass` 先委派父加载器，父找不到再由子加载。
- `findClass` 定义加载器的实际加载逻辑。

## 4. 关键点/注意事项

- 破坏双亲委派常用于隔离与热部署（如 Tomcat、OSGi）。
- 自定义类加载器需避免类重复加载导致的 `ClassCastException`。
