# 线程的生命周期介绍

## 1. 结论

Java 线程生命周期包括 NEW、RUNNABLE、BLOCKED、WAITING、TIMED_WAITING 与 TERMINATED 六种状态。

## 2. 状态流转

- NEW：创建但未调用 `start()`。
- RUNNABLE：就绪或运行中。
- BLOCKED：等待获取监视器锁。
- WAITING：`wait()`/`join()` 等无超时等待。
- TIMED_WAITING：`sleep()`/`wait(timeout)` 等有超时等待。
- TERMINATED：执行结束。

## 3. 关键点/注意事项

- `start()` 只能调用一次。
- `wait()` 会释放锁，`sleep()` 不会。
