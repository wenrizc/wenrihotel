# Vector 与 ArrayList 区别

## 1. 核心区别
| 维度 | Vector | ArrayList |
| --- | --- | --- |
| 线程安全 | 方法级同步 | 非线程安全 |
| 扩容策略 | 默认 2 倍扩容或自定义增量 | 默认 1.5 倍扩容 |
| 性能 | 同步开销较大 | 更快 |
| 时代定位 | 早期遗留类 | 主流选择 |

## 2. 扩容与性能影响
`Vector` 在高并发下因为内置同步会带来额外开销，而 `ArrayList` 在单线程或只读场景性能更好。扩容时两者都会进行数组复制，频繁扩容会导致额外 GC 与延迟波动，因此应提前设置合理容量。

## 3. 线程安全选择建议
可以根据并发写入程度做选择。

- 单线程或只读场景优先使用 `ArrayList`。
- 多线程写场景可用 `Collections.synchronizedList` 或 `CopyOnWriteArrayList`。
- 高并发写场景需要结合锁、分段或无锁结构综合评估。

## 4. 常见追问/易错点
面试中常见的追问如下。

- 追问：`Vector` 是不是一定更安全？
  - 答：它只保证单个方法线程安全，复合操作仍可能出现竞态。
- 易错点：把 `Vector` 当作并发容器使用。
  - 答：高并发下更推荐 `CopyOnWriteArrayList` 或专用并发容器。
