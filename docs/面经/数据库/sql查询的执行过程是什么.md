# SQL查询的执行过程是什么

## 1. 结论

SQL 查询大致经历解析与预处理、优化生成执行计划、执行器调用存储引擎访问数据并返回结果。

## 2. 主要步骤

1. 解析：词法/语法解析生成语法树。
2. 预处理：权限检查、语义校验。
3. 优化：生成并选择执行计划（索引、连接顺序）。
4. 执行：执行器驱动存储引擎读取数据。
5. 返回：结果集发送到客户端。

## 3. 关键点/注意事项

- 优化器选择的计划不一定最优，需要 `EXPLAIN` 验证。
- Buffer Pool 命中率影响读性能。
