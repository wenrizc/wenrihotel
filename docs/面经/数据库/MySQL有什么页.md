## 1. 常见页类型

- 数据页/索引页：存放记录与 B+ 树节点。
- Undo 页：保存回滚与 MVCC 版本。
- 系统页：管理表空间与元数据。
- Insert Buffer（Change Buffer）页：优化非唯一索引写入。

## 2. 关键点/注意事项

- 页分裂与合并会影响写入性能。
- Buffer Pool 以页为单位缓存热点数据。
