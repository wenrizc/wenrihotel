# 索引失效的场景

## 1. 结论

索引失效多发生在条件不可走索引、左前缀被破坏或类型转换导致无法使用索引。

## 2. 常见失效场景

- 对索引列使用函数或表达式（如 `DATE(col)`）。
- 前缀模糊匹配（`LIKE '%xxx'`）。
- 隐式类型转换（字符串与数字比较）。
- 联合索引未遵循左前缀。
- OR 条件两边只有一侧有索引。

## 3. 规避与优化

- 改写条件为可走索引的形式。
- 合理设计联合索引顺序。
- 使用 `EXPLAIN` 验证执行计划。
