## 1. ACID 特性

- 原子性（Atomicity）：全部成功或回滚。
- 一致性（Consistency）：执行前后满足约束。
- 隔离性（Isolation）：并发事务互不干扰。
- 持久性（Durability）：提交后结果持久保存。

## 2. 常见示例

- 转账：扣款与加款必须同时成功或失败。

- 易错点：把“ACID”误理解为都是数据库自动保证。
