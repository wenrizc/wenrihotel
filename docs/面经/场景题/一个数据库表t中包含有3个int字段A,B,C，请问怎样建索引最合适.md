# 一个数据库表t中包含有3个int字段A,B,C，请问怎样建索引最合适

## 1. 结论

索引设计应以实际查询条件为准，优先建立符合“最常用条件 + 左前缀”原则的联合索引，如常见查询是 A、A+B、A+B+C，则推荐 (A,B,C)。

## 2. 设计思路

- 统计主要查询：WHERE、JOIN、ORDER BY、GROUP BY 的组合。
- 将选择性高、过滤性强的列放在联合索引前部。
- 保证联合索引覆盖最核心的查询组合，避免冗余索引。

## 3. 常见场景示例

- 若查询多为 `A=?`、`A=? AND B=?`、`A=? AND B=? AND C=?`，选 `(A,B,C)`。
- 若存在大量 `B=?` 或 `C=?` 的独立查询，需额外建立单列索引。

## 4. 注意事项

- 范围条件会截断左前缀，范围字段不宜放在最前面。
- 过多索引会增加写入成本与维护成本。
