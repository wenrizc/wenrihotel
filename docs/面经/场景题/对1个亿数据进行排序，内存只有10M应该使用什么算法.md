# 对1个亿数据进行排序，内存只有10M应该使用什么算法

## 1. 结论

内存不足以放下全量数据时，应使用外部排序（多路归并排序），将数据分块排序后落盘，再进行归并。

## 2. 核心流程

1. 分块读取：按内存容量将数据切分为多个块。
2. 内存排序：每个块在内存中用快排/归并排序。
3. 有序落盘：将每个已排序块写入临时文件。
4. 多路归并：使用小根堆合并多个有序文件，输出最终有序结果。

## 3. 关键点/注意事项

- 块大小要预留缓冲区与堆空间，避免频繁 GC 或 I/O 抖动。
- 归并时用缓冲区批量读写，减少磁盘随机 I/O。
- 可通过增加归并路数或两阶段归并降低总轮数。

## 4. 适用场景与局限

- 适用于数据量远超内存的离线排序。
- 局限是磁盘 I/O 成本高；若有分布式环境，可用 MapReduce/Spark 优化。
