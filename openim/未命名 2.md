## 📁 推送模块总体架构

这是 OpenIM 的推送模块，主要负责消息的在线推送和离线推送功能。

## 🔧 核心文件功能详解

### 1. **主入口文件**

#### push.go - 推送服务主入口
- **功能**: 推送服务的启动和配置初始化
- **职责**: 
  - 创建推送服务实例
  - 初始化数据库连接、Redis缓存
  - 配置离线推送器
  - 启动消息队列监听

### 2. **推送处理器**

#### push_handler.go - 主推送消息处理器
- **功能**: 处理从消息队列接收到的推送消息
- **职责**:
  - 接收 Kafka 消息队列的推送消息
  - 区分单聊和群聊消息
  - 判断用户是否在线，决定进行在线推送还是离线推送
  - 调用 webhook 回调
  - 过滤需要推送的用户列表

#### offlinepush_handler.go - 离线推送处理器
- **功能**: 专门处理离线推送消息
- **职责**:
  - 从消息队列接收离线推送任务
  - 解析推送内容（标题、内容、推送选项）
  - 调用具体的离线推送服务商

### 3. **在线推送模块**

#### `onlinepusher.go` - 在线推送器
- **功能**: 处理在线用户的消息推送
- **职责**:
  - 获取用户连接信息
  - 通过 WebSocket 向在线用户推送消息
  - 支持多种推送策略（全节点推送、一致性哈希等）
  - 处理推送失败的用户ID

### 4. **离线推送核心**

#### offlinepusher.go - 离线推送器工厂
- **功能**: 离线推送服务商的统一接口和工厂
- **职责**:
  - 定义 `OfflinePusher` 接口
  - 根据配置创建不同的推送服务商实例（个推、FCM、JPush、Dummy）

### 5. **推送服务商实现**

#### push.go - 虚拟推送器
- **功能**: 默认的空推送实现
- **职责**: 当没有配置任何推送服务时的占位符实现

#### push.go - Firebase推送
- **功能**: Firebase Cloud Messaging 推送实现
- **职责**:
  - 集成 Firebase Admin SDK
  - 发送 Android/iOS 推送通知
  - 处理推送结果和错误

#### push.go - 个推推送
- **功能**: 个推（GeTui）推送服务实现
- **职责**:
  - 个推 API 认证和token管理
  - 单推和批量推送
  - 任务ID管理

#### `getui/body.go` - 个推数据结构
- **功能**: 定义个推API的请求响应数据结构

#### push.go - 极光推送
- **功能**: 极光推送（JPush）服务实现
- **职责**:
  - 极光推送 API 集成
  - 构造推送请求对象
  - 处理推送认证

### 6. **极光推送数据结构**

#### `jpush/body/` 目录下的文件：
- **`audience.go`**: 定义推送目标受众（标签、别名、注册ID等）
- **`message.go`**: 定义推送消息结构
- **notification.go**: 定义通知内容（Android/iOS 特定设置）
- **`options.go`**: 推送选项配置
- **`platform.go`**: 目标平台设置（Android、iOS等）
- **pushobj.go**: 推送对象的完整结构

### 7. **配置和选项**

#### `options/options.go` - 推送选项
- **功能**: 定义推送的通用选项
- **职责**: 
  - iOS 推送声音设置
  - 角标计数配置
  - 扩展信息
  - 消息ID信号

### 8. **回调处理**

#### callback.go - Webhook回调处理
- **功能**: 处理推送相关的 webhook 回调
- **职责**:
  - 离线推送前的回调验证
  - 在线推送前的回调验证
  - 群组推送前的回调验证
  - 解析消息内容用于回调

## 🔄 工作流程

1. **消息接收**: push_handler.go 从 Kafka 接收推送消息
2. **用户状态判断**: 检查用户是否在线
3. **在线推送**: 通过 `onlinepusher.go` 向在线用户推送
4. **离线推送**: 将离线用户消息发送到离线推送队列
5. **离线处理**: offlinepush_handler.go 处理离线推送队列
6. **服务商选择**: 根据配置选择具体的推送服务商
7. **消息发送**: 调用对应服务商的 API 发送推送

这个模块设计非常完善，支持多种推送服务商，具有良好的扩展性和容错机制。
